# Energy Transfers 
Our body **requires energy to perform** [[Exercise and Fitness#Physical Activities & Exercise]], maintain body temperature, and a healthy metabolism. With this, there are **two ways** energy is constantly being consumed/transferred: 
1. Basal Metabolic Rate: this is the consumption of energy to maintain **bodily function and survival**. No motion is required for this. 
2. Working Energy: this is the consumption of energy when we **work or play**. 

This energy is derived from a molecule called **Adenosine Triphosphate** (ATP). But because ATP can only be stored in small amounts in muscles, any activity that last longer than a few seconds requires more energy to be produced.  
# Energy Producers 
## Anaerobic Systems
Anaerobic means that in order to produce ATP, no oxygen is required. It is inefficient since it only produces 1/20 energy. But because it is **faster**, it is suitable for **high intensity activities for short time.** 
### ⚡Anaerobic ATP-PCr

| Feature                 | Description                                                |
| ----------------------- | ---------------------------------------------------------- |
| Fuel source             | Phosphocreatine (PCr) stored in muscles                    |
| Duration of energy      | **5–15 seconds**                                           |
| By-products             | None (no lactic acid)                                      |
| Examples of activity    | Sprinting (100m), powerlifting, jumping, diving, high jump |
- [p] **Key advantage**: Immediate energy supply
- [c] **Key disadvantage**: Quickly depleted
### 🔥Glycolytic System 

| Feature                 | Description                                                  |
| ----------------------- | ------------------------------------------------------------ |
| Fuel source             | Glucose (from blood or glycogen)                             |
| Duration of energy      | **1 – 2 minutes**                                            |
| By-products             | **Lactic acid (lactate + H⁺)**                               |
| Examples of activity    | 400m sprint, swimming 100m, high-intensity interval training |
- [p] **Key advantage**: Provides energy for moderate duration and high-intensity
- [c] **Key disadvantage**: Lactic acid buildup leads to fatigue (muscle burn)
## 🔁 Aerobic System 
Aerobic system requires oxygen in order to produce ATP (also known as Cellular Respiration). 

| Feature                 | Description                                              |
| ----------------------- | -------------------------------------------------------- |
| Fuel source             | Carbohydrates, fats (and sometimes protein)              |
| Speed of ATP production | **Slow**                                                 |
| Duration of energy      | **Long-lasting (several minutes to hours)**              |
| By-products             | CO₂ + H₂O (non-fatiguing)                                |
| Examples of activity    | Long-distance running, biking, walking, endurance sports |
- [p] **Key advantage**: Can produce **a lot of ATP** over time
- [c] **Key disadvantage**: Too slow for high-intensity bursts
