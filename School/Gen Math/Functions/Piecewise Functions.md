
> [!question] What is a piecewise function?
> It is a **condition-based function** that is defined by different formulas or expressions **depending** on the **input (x)** value.

$$
f(x)=\begin{cases} x^2 & if \ \ x < 0 \\ x+2   & if \  \ x\ge 0 \end{cases}
$$
- [I] This is an example of a **piecewise function**
- [!] This function states that: 
	- if x < 0, then use $f(x)=x^2$
	- if x $\ge$ 0, then use $f(x)=x+2$

> [!example]
> > [!question]-
> > >$$
> > > let \ \ f(x)=\begin{cases}
> > > x^2+3x-7 & x<-1 \\ 
> > > 5x+6 & -1\le x < 2  \\
> > > x^3+4 & x>2 \\
> > > 12 & x=2
> > > \end{cases} 
> > > $$
> > > $$
> > > \begin{aligned}
> > > &find \ \ f(x) \ \  if: \\
> > > &f(-4) \ \ f(0) \ \ f(2) \ \ f(4)
> > > \end{aligned}
> > > $$
> 
> > [!check]- Answer
> > > $$
> > > \begin{aligned}
> > > &f(-4)=(-4)^2+3(-4)-7=-3 \\ 
> > > &f(0) = 5(0)+6=6 \\
> > > &f(2)=12\\
> > > &f(4)=(4)^3+4=68
> > > \end{aligned}
> > > $$
