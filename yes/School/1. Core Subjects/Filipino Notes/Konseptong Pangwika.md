# Bilingguwalismo
Ito ang kakayahan ng isang tao/komunidad makapagsalita ng dalawang wika. Ang mga layunin ng Billingguwalismo: 
1. Mataas ang pakatuto
2. Wikang Filipino bilang wika ng literasi 
3. Filipino bilang pambansang identidad 
4. Filipino bilang akademikong diskuro (academic discourse)
5. Ingles bilang internasyonal na wika (lingua franca) sa siyensiya at tech
